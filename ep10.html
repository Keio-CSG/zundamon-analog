3容量の由来（断面図） 動画 0:34

め

四国めたん

第1回の断面図に戻りましょう。p型の基板に、n型のソースとドレインね。

四国めたん：容量は、2つの導体が、絶縁物をはさんで向き合うところにできるのよ。

め

四国めたん

まずはゲートとチャネル。薄い酸化膜をはさんで、コンデンサを作るの。

四国めたん：飽和領域のチャネルは、ソースにつながっている。だから、これはCgsになるわ。

四国めたん：長チャネルの飽和領域なら、大きさは、Cgs≈(2/3)WLCoxよ。

め

四国めたん

Coxは、酸化膜の単位面積あたりの容量ね。

ず

ずんだもん質問

ゲートの面積の、3分の2だけなのだ？

め

四国めたん

チャネルはドレインに近いほど薄いでしょう？だから電荷は、一様なときの3分の2なの。

四国めたん：容量は、電荷の変化を電圧の変化で割ったもの。その比も3分の2になるの。

め

四国めたん

次はCgd。ゲートの端は、ソースやドレインに少し重なっているの。

四国めたん：この重なりを、オーバーラップと呼ぶわ。ソース側の分は、Cgsに足されるの。

め

四国めたん

チャネルはドレインの手前で途切れるから、Cgdはほぼオーバーラップの分だけよ。

め

四国めたん

もう1つは、ドレインと基板のpn接合。空乏層が、絶縁物の役をするの。

四国めたん：これがCdb。ソース側のCsbは、ソースも基板もグラウンドなので、効かないの。

め

第3回の小信号モデルに、この容量を描き足しましょう。

め

CgsはGとSの間、CgdはGとDの間。CdbはDと基板（グラウンド）の間よ。

5容量のインピーダンスと RC の周波数特性 動画 2:14

ず

ずんだもん質問

容量があると、どうして利得が変わるのだ？周波数も関係あるのだ？

め

四国めたん

コンデンサは、直流は通さないけれど、交流は通すの。

四国めたん：しかも、周波数が高いほど、交流を通しやすくなるわ。

め

四国めたん

低い周波数では、電流がほとんど流れず、開放と同じ。だから第3回では省略できたの。

め

四国めたん

容量のインピーダンスは1/(jωC)。周波数が上がるほど、小さくなるの。

め

四国めたん

Cgsでも、1GHzで約38 kΩ、10GHzでは約3.8 kΩよ。

ず

ずんだもん質問

そんなに小さくなったら、ゲートに電流が流れるのだ？

め

四国めたん

そうよ。高い周波数では、ゲートの電荷を出し入れする交流の電流が流れるの。

四国めたん：絶縁膜を電流が突き抜けるわけではないわ。「ゲートは開放」は低い周波数の話ね。

め

四国めたん

まずは、信号源の抵抗RSとCgsだけで考えましょう。RSは10 kΩにするわ。

め

四国めたん

RSとCgsの分圧ね。Cgsのインピーダンスが下がると、ゲートの電圧も下がるの。

四国めたん：ゲートの電圧が小さくなれば、増幅する前の信号が小さい。だから利得も下がるの。

め

四国めたん

つまりこれは、ローパスフィルタ（低域フィルタ）。低い周波数を通し、高い周波数を弱めるの。

ず

ずんだもん質問

高い周波数ほど弱まるのを、どうやって見るのだ？

め

四国めたん

それを見るのが、ボード線図。周波数ごとの利得と位相を、1枚に描くの。

め

四国めたん

上の段は利得の大きさ、下の段は位相。同じ周波数で読むのよ。

め

四国めたん

横軸は周波数の対数。目盛りが1つ進むと、周波数は10倍よ。

ず

ずんだもん質問

どうして普通の目盛りじゃないのだ？

め

四国めたん

普通の目盛りだと、10MHzから1GHzが、いちばん左に固まってしまうの。対数なら等間隔よ。

め

四国めたん

デシベルは、電圧利得の大きさを20log10で表したもの。1倍が0dBね。

四国めたん：10倍なら＋20dB、10分の1なら−20dB。

め

四国めたん

1/√2倍は約−3dB。マイナスは、1倍より小さい、という意味よ。

め

四国めたん

では、周波数を低いほうから、上げていくわよ。

め

四国めたん

低い周波数では、利得はほぼ0dB。入力がそのまま出てくるの。

め

四国めたん

1/(ωCgs)がRSと等しい約3.8GHzで、−3dB。大きさが1/√2になるの。

め

四国めたん

この点を、カットオフ周波数、または遮断周波数と呼ぶわ。

ず

ずんだもん質問

どうして3dBで区切るのだ？

め

四国めたん

電力が半分になる点だからよ。振幅なら1/√2、約7割ね。

め

四国めたん

波を見ると、出力の振幅は入力の約7割。少し遅れてもいるわ。

四国めたん：それより十分高いと、周波数が10倍ごとに、利得は約20dBずつ下がるわ。

め

四国めたん

約38GHzは、カットオフの10倍。インピーダンスも振幅も、約10分の1ね。

ず

ずんだもん質問

波が遅れるって、どういうことなのだ？

め

四国めたん

位相は、出力の波が入力からずれる角度。1周期が360°で、遅れはマイナスで描くわ。

四国めたん：位相は、低い周波数で0°。−3dBの点で45°遅れ、その先は90°遅れに近づくの。

め

四国めたん

カットオフ周波数は1/(2πRSCgs)。抵抗と容量の積、時定数で決まるのよ。

ず

ずんだもん

抵抗か容量が大きいほど、カットオフ周波数は低くなるのだ！

め

四国めたん

そのとおり。時定数がいくつかあっても、1つが飛び抜けて大きければ、それが帯域をほぼ決めるの。

6ソース接地増幅回路の周波数特性 動画 5:55

ず

ずんだもん質問

部品が全部入ったら、どうやって計算するのだ？

め

四国めたん

ソース接地増幅回路に、RSと容量を全部入れて、周波数ごとに節点方程式を解くわ。

め

四国めたん

さっきと同じ順番で読みましょう。まずは、低い周波数の利得ね。

四国めたん：低い周波数では、利得は約4倍の12dB。第3回と同じね。

ず

ずんだもん質問

12dBって、12倍のことなのだ？

め

四国めたん

違うわ。dBは対数よ。6dBで約2倍だから、12dBは約2×2=4倍なの。

め

四国めたん

低い周波数の利得から3dB下がるのが、約1.8GHz。ここまでを帯域と呼ぶわ。

四国めたん：帯域とは、利得がほぼ平らで、ほぼ同じ倍率で増幅できる範囲のことよ。

め

四国めたん

RCのときと同じく、低い周波数から、3dB下がる点を、カットオフ周波数と呼ぶの。

四国めたん：第8回や第9回で出てきた帯域も、同じ−3dBの点で測っていたのよ。

ず

ずんだもん質問

帯域が広いと、何がうれしいのだ？

め

四国めたん

速い信号まで、ほぼ同じ倍率で増幅できるの。

め

四国めたん

狭いと、速い変化がぼやけて、立ち上がりが遅くなるわ。

め

四国めたん

位相は、反転の180°に加えて、周波数が上がるほど遅れていくの。

め

四国めたん

グラフは反転を除いた遅れ。−3dBの点では約50°よ。

四国めたん：45°より多いのは、出力側の容量が効くからよ。

四国めたん：Cgdだけを外して解くと、帯域は約3.6GHz。Cgdで、帯域が約半分になったの。

ず

ずんだもん質問

CgdはCgsの5分の1もないのだ。どうしてそんなに効くのだ？

7ミラー効果 動画 7:34

め

四国めたん

それがミラー効果よ。ポイントは、Cgdが入力と出力の間にあることなの。

ず

ずんだもん質問

ミラーって、第4回のカレントミラーの仲間なのだ？

め

四国めたん

別物よ。真空管の時代にこの効果を調べた、Millerという人の名前なの。

め

四国めたん

入力が1 mV上がると、出力は約4倍の4 mVだけ下がるわね。

め

四国めたん

するとCgdの両端の電圧差は、1−(−4)＝5 mV。入力の5倍も変わるの。

ず

ずんだもん

もう片方が逆向きに大きく動くから、差が広がるのだ！

め

四国めたん

そうね。電圧が5倍速く変わるので、電流も5倍。入力から見ると5倍の容量なの。

め

四国めたん

利得を低い周波数の値で近似すると、Cgdは(1＋|Av|)倍に見える。これがミラー容量よ。

ず

ずんだもん質問

ミラー容量って、結局なんなのだ？本当にその容量があるのだ？

め

四国めたん

いいえ、本物の容量が増えるわけではないの。

め

四国めたん

入力から見ると、Cgdが(1＋|Av|)倍の容量に見えるだけよ。

四国めたん：Cgdの両端の電圧が、入力の(1＋|Av|)倍の速さで変わるからね。

め

四国めたん

信号源の抵抗RSは、この見かけの容量も充電しなければならないの。

め

四国めたん

すると入力の時定数が大きくなり、帯域が下がるの。数値はこのあと見るわ。

ず

ずんだもん

見かけの容量でも、充電の手間は本物なのだ！

め

四国めたん

出力側から見ると(1+1/|Av|)倍。こちらは、ほぼCgdのままね。

め

四国めたん

この回路のミラー容量は約4.0fF。Cgsの4.2fFと、ほぼ同じよ。

め

四国めたん

入力の容量は、合わせて約8.2fF。Cgsだけのときの約2倍ね。

め

四国めたん

RSとの時定数で見積もると約1.9GHz。数値で解いた1.8GHzと、ほぼ合うわ。

ず

ずんだもん質問

出力側にも容量があるのに、そっちは効かないのだ？

め

四国めたん

実際が少し低いのは、出力側の時定数も、わずかに効くからよ。

め

四国めたん

出力側は、RD∥ro≈4.6 kΩ、容量は約3fF。時定数は入力の約6分の1よ。

四国めたん：さっきの話ね。1つの時定数が飛び抜けて大きいと、それが帯域をほぼ決めるの。

ず

ずんだもん

今回は入力の時定数がずっと大きいから、帯域をほぼ決めるのだ！

め

四国めたん

利得を上げるほど、ミラー容量も大きくなる。利得と帯域の取り合いね。

め

四国めたん

第4回の能動負荷では、利得が約35倍。Cgdは約36倍にも見えるわ。

め

四国めたん

第6回のカスコードなら、M1のドレインはあまり動かない。ミラー効果も小さくなるの。

8遷移周波数 fT 動画 10:15

ず

ずんだもん質問

トランジスタそのものは、どのくらい速く動けるのだ？

め

四国めたん

その目安が、遷移周波数fT。電流利得の大きさが1になる周波数よ。

め

四国めたん

直流の動作点は保ち、ドレインを交流的にグラウンドにして、ゲートに電流を入れるの。

め

四国めたん

出力の電流はほぼgm·vgs。入力の電流は容量を流れるので、周波数に比例して増えるの。

め

四国めたん

比が1になる周波数が、fT≈gm/(2π(Cgs+Cgd))ね。

め

四国めたん

この例では、fTは約28GHz。帯域の1.8GHzより、ずっと高いわね。

ず

ずんだもん質問

トランジスタは速いのに、回路の帯域はずっと低いのだ？

め

四国めたん

そうなの。回路の帯域は、RSやRDとの時定数とミラー効果で決まるの。fTは単体の目安よ。

め

四国めたん

fTを上げるには、gmを大きく、容量を小さく。Lを短くすると、その両方に効くの。

9まとめ 動画 11:14

め

四国めたん

まとめましょう。MOSFETには、Cgs・Cgd・Cdbなどの容量があるわ。

め

四国めたん

ミラー容量とは、反転増幅のCgdが、入力から(1＋|Av|)倍に見えること。

RSと容量はローパスフィルタ。飛び抜けて大きな時定数が、帯域をほぼ決めるの。
