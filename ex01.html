2プレーナー型と短チャネル効果・DIBL 動画 0:27

め

四国めたん

最初はプレーナー型。前に見た、基板の表面に通り道を作る形ね。

四国めたん：これはIntel公開の顕微鏡写真よ。ゲートの下の基板表面を使う、平らな構造なの。

め

四国めたん

NMOSでは、ゲート電圧を上げると、絶縁膜の向こう側に電子が集まるの。

四国めたん：電流はソースとドレインの間を流れる。ゲートは、その通り道を上から制御するわ。

ず

ずんだもん

小さくすれば、同じチップにたくさん並べられるのだ！

め

四国めたん

そうね。でも、チャネルを短くするだけでは、電流を止めにくくなるの。

め

四国めたん

ソースとドレインが近づくと、ドレインの電界も通り道に強く入り込むわ。

め

四国めたん

オフでは、ソースの電子が越えるエネルギーの山を、ゲートで高くしておきたい。

め

四国めたん

ところがドレイン電圧を上げると、その山が下がって電子が入りやすくなるの。

四国めたん：これがDIBL。ドレインによって、電子の越える障壁が低くなる現象よ。

ず

ずんだもん

ゲートで止めたつもりでも、ドレインの影響で漏れてしまうのだ。

め

四国めたん

短チャネル効果では、しきい値の変化や、オンとオフの切れの悪化も問題になるわ。

め

四国めたん

大事なのは、通り道の電位をゲートがどれだけ強く決められるか、なの。

め

四国めたん

プレーナー型も、成熟した製造技術を使う回路などで、今も役に立っているの。

ず

ずんだもん

もっと小さくしたいときは、ゲートで横からも囲めばよさそうなのだ。

3FinFET：上と左右の3面から制御（Intelが最初に量産） 動画 1:46

め

四国めたん

その発想がFinFETよ。シリコンを、薄いヒレのように立てるの。

四国めたん：Intelの実物写真では、細いヒレと、それを横切るゲートが見えるわ。模式図と比べてね。

め

四国めたん

電流の進む向きに直角に切ると、こんな断面になるわ。

四国めたん：ここで示す形は、上と左右の3面を、絶縁膜を挟んだゲートで囲むの。

め

四国めたん

周りのゲートはつながっていて、同じ電圧で制御するわ。

四国めたん：細いヒレを複数の面から制御するので、ドレインに邪魔されにくくなるの。

ず

ずんだもん質問

前に習ったチャネル幅Wは、どこになるのだ？

め

四国めたん

大まかには、上の幅と、左右の高さを足した長さが、1本分の幅になるわ。

め

四国めたん

同じヒレを横に増やすと、電流の通り道も増える。幅は本数刻みで変わるの。

め

四国めたん

FinFETを量産で最初に使ったのは、Intelなの。

め

四国めたん

Intelは2011年、22 nm世代のTri-Gateを発表したわ。

め

四国めたん

2012年には、それを使ったIvy BridgeのCore製品を発売したの。

ず

ずんだもん

世界初の22 nm・Tri-Gate採用CPUが、パソコンに入ったのだ。すごいのだ！

め

四国めたん

これは同じ22 nm世代の、サーバー向けのダイ写真よ。作者名は画面の隅を見てね。

め

四国めたん

14 nm、7 nm、4 nmの世代のダイも並べたわ。縮尺はそろえていないの。

め

四国めたん

回路ブロックの配置が見えるわ。配線層をはがした写真も含まれるの。

4GAA：ナノシートの全周を囲む 動画 3:12

ず

ずんだもん質問

じゃあGAAでは、さらにどう変わるのだ？

め

四国めたん

ゲート・オール・アラウンド。通り道の断面を、ゲートでぐるっと囲むの。

め

四国めたん

今回見るナノシート型は、薄い板状のチャネルを、縦に積み重ねた形よ。

四国めたん：IBMの断面写真には、横長のシートが重なって見えるわ。周囲をゲートで囲む構造よ。

め

四国めたん

板と板の間にもゲートが入り、絶縁膜を挟んで、各シートの全周を囲むわ。

ず

ずんだもん質問

縦に積んでも、電流は板に沿って、ソースとドレインの間を流れるのだ？

め

四国めたん

その通り。ここではシートを並列につなぐの。上下へ順番に流すわけではないわ。

四国めたん：下側からも制御できるので、さらに短いチャネルで、電流を止めやすくなるの。

め

四国めたん

シートの幅も設計の調整に使える。ヒレの本数で調整するFinFETとは違うわ。

め

四国めたん

ただし、熱で電子が山を越える性質は残るわ。GAAでも、理想のスイッチではないの。

め

四国めたん

通常のMOSFETは、室温の弱反転で、電流を10倍にするゲート電圧の変化は約60 mV以上よ。

め

四国めたん

しかも、薄い板を残して周りにゲートを作るので、製造はさらに難しくなるの。

ずんだもん質問

先にSamsungが、2022年6月に、3 nmのGAAロジックで初期生産を発表したわ。

め

め

四国めたん

72 nmはどこの長さ？ 2026年10月の最先端 動画 5:27

ず

ずんだもん質問

ところで2 nmって、トランジスタのどこの長さなのだ？

め

四国めたん

今の2 nmや3 nmは、製造技術の世代名よ。ゲートの長さそのものではないの。

め

四国めたん

例えばIBMの2 nm研究試作では、ゲート長は12 nmと説明されているわ。

め

四国めたん

先端ロジックでは、2 nm世代のN2や18Aなどが、量産・生産中よ。

め

め

四国めたん

Intelは18Aが生産中。14Aは、自社製品向けに2027年後半リスク生産の計画よ。

ず

ずんだもん質問

iPhoneやMacでは、チップがどんなふうに変わってきたのだ？

四国めたん

Appleの発表と分解調査の報告を分けて、年表を見ていきましょう。

め

四国めたん

2013年のA7は、分解調査でSamsungの28 nm製と報告されたわ。

め

四国めたん

2015年のA9は、同じく分解調査で、FinFETのチップと報告されたの。

め

四国めたん

ただしAppleの発表文には、構造も製造会社も書かれていないの。

め

四国めたん

2018年のA12は7 nm。Appleがスマホ初の7 nmチップと発表したの。

め

四国めたん

2020年のA14は5 nmで、118億個のトランジスタを載せていたわ。

め

四国めたん

同じ年のM1も5 nmで、160億個。こちらはMacなどに使われたチップね。

め

四国めたん

2023年のA17 Proは3 nm。Appleは業界初の3 nmチップと説明したわ。

め

四国めたん

2023年のM3は3 nmで250億個。M3 ProやMaxとは別の、基本モデルよ。

め

四国めたん

2024年のM4は、第2世代の3 nmで、280億個になったの。

め

四国めたん

総数は、面積や回路の構成でも変わるわ。速さも、個数には比例しないの。

め

四国めたん

2025年のM5は、第3世代の3 nm。同じ3 nmの中でも改良が続いたわ。

め

四国めたん

2026年8月、AppleはM6を、同社初の2 nmチップとして発表したの。

め

四国めたん

同じ年の9月には、iPhone向けのA20 Proも、2 nmと発表されたわ。

め

四国めたん

ただし、このAppleの発表文だけでは、製造会社やGAA構造までは確認できないの。

10CFET：NMOSとPMOSを上下に積む 動画 8:25

め

四国めたん

さらに先では、NMOSとPMOSを縦に積むCFETなども研究されているわ。

ず

ずんだもん

シートを積む話とは違って、今度は2種類のトランジスタを積むのだ！

ず

ずんだもん質問

でも、どうしてNMOSとPMOSを上下に置きたいのだ？

め

四国めたん

CFETでは、NMOSとPMOSの2つの素子を、上下に重ねるのよ。

四国めたん：imecの試作断面写真では、上にnFET、下にpFETがあるわ。これは配置の一例ね。

め

四国めたん

横に並べる場所を減らせるので、同じ論理回路を、より小さな面積に収めやすくなるわ。

四国めたん：課題もあるわ。上下の素子へ配線を届け、抵抗や余計な容量も抑える必要があるの。

め

四国めたん

発生した熱を外へ逃がすことも大事。密に積めば、それだけ設計が難しくなるわ。

四国めたん：imecなどが試作や研究を進めているけれど、広く量産で使われている段階とは分けて見てね。

ず

ずんだもん

GAAは通り道を囲む工夫、CFETはNとPの素子を積む工夫。両方を組み合わせるのだ！

11裏面給電：信号と電源の配線を分ける 動画 9:24

ず

ずんだもん質問

裏面給電という言葉も見たのだ。これも、トランジスタの形の話なのだ？

め

四国めたん

こちらは電源の届け方の工夫よ。Backside Power Delivery、裏面給電ね。

四国めたん：従来は表側の配線に信号も電源も通すけれど、裏面給電では電源を裏側へ回して届けるわ。

め

四国めたん

狙いの1つは、電源配線の抵抗を下げ、電流が流れるときの電圧降下を小さくすること。

ず

ずんだもん

GAAやCFETは素子の構造や置き方、裏面給電は電源の配り方。別の工夫なのだ。

め

四国めたん

Intel 18Aは、RibbonFETと裏面給電のPowerViaを組み合わせるわ。

ず

ずんだもん

素子だけ小さくしても足りないのだ。電源を届ける道まで、一緒に進化させるのだ！

12アナログ回路に適したプロセスとは？ 動画 10:12

ず

ずんだもん質問

形が変わると、アナログ回路で習うことも全部変わるのだ？

め

四国めたん

ゲート電圧で電流を制御する考え方や、gm、出力抵抗という見方は引き続き使えるわ。

め

四国めたん

ただし、先端素子の数値を、前の単純な2乗則だけで予測することはできないの。

め

四国めたん

それに、アナログ回路には、信号を振らせたり素子を重ねたりする電圧の余裕が必要なの。

め

四国めたん

電圧の余裕、精度、使える素子、費用を考えると、成熟したプロセスが適する場合も多いわ。

め

四国めたん

ただし一律ではないわ。高速な入出力回路など、先端プロセスが役立つアナログ回路もあるの。

13アナログと先端デジタル：チップレットで使い分ける 動画 10:51

ず

ずんだもん質問

アナログとデジタルで、得意な製造プロセスを使い分けられないのだ？

め

四国めたん

そこでチップレットよ。機能ごとの小さなチップをつないで、1つのシステムにするの。

四国めたん：例えば、アナログは成熟プロセス、デジタルの演算部は先端で作って、同じパッケージへ。

め

四国めたん

高価な先端プロセスを必要な部分に使えるの。大きな1枚のチップを分ける狙いもあるわ。

142.5Dと3D、ハイブリッドボンディング 動画 11:14

め

四国めたん

2.5D集積では、チップを横に並べて、細かな配線でつなぐの。

め

四国めたん

例えば、インターポーザという中継基板を下に置く。普通の基板より密な接続を作れるわ。

め

四国めたん

3D集積では、チップを上下に積んで、縦方向につなぐの。横の面積や接続距離を減らせるわ。

ず

ずんだもん質問

上下のチップは、どうやって細かくつなぐのだ？

め

四国めたん

方法の1つが、ハイブリッドボンディング。絶縁膜どうしと、銅の電極どうしを接合するの。

め

四国めたん

接合面にはんだバンプを使わず、微細な間隔で、多くの電気的な接続を作れるわ。

ず

ずんだもん

CFETは素子、ここでいう3D集積はチップを積む話。立体にする場所が違うのだ。

め

四国めたん

ただし、接続の設計や検査、放熱は難しくなるし、パッケージの費用も増えるわ。

め

四国めたん

必ず安くなるわけではないの。性能と費用を合わせて、全体でよい組み合わせを選ぶのよ。

ず

ずんだもん

全部をいちばん細かく作るより、得意な技術を組み合わせて、いいとこ取りするのだ！
