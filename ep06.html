第6回

カスコード：出力抵抗を大きくする

アナログ回路入門シリーズ第6回です。電源電圧はそのままで、もっと利得を上げたい……そこで登場するのがカスコードです。

ソース接地の上にゲート接地を積むと、なぜ出力抵抗が大きくなるのか（シールド効果）を大信号の数値で確かめ、テスト電源を当てた小信号回路から Rout ≈ (gm+gmb)ro2·ro1 を導きます。カスコードカレントミラー、カスコード増幅回路、そして代償としての電圧の余裕（ヘッドルーム）まで扱います。

3カスコードの構成 動画 0:42

め

四国めたん

ソース接地のM1の上に、ゲート接地のM2を縦に積むの。これがカスコードよ。

四国めたん：M2のゲートは、一定の電圧Vbに固定。間のノードをXと呼ぶわ。

め

四国めたん

直列だから電流は同じ。M1が入力を電流に変えて、M2がそれを上へ渡すの。

四国めたん：M2の基板はグラウンドで、ソースはX。基板バイアス効果も入れて解くわ。

4なぜ出力抵抗が上がるのか 動画 1:21

どうして、積むだけで出力抵抗が大きくなるのだ？

め

め

四国めたん

出力を1.0 Vから1.5 Vに上げても、VXは約6 mVしか動かないの。

ず

ずんだもん

M1から見ると、VDSがほとんど変わらないのだ！

め

四国めたん

め

四国めたん

5小信号回路で出力抵抗を求める 動画 2:11

め

四国めたん

出力抵抗を式で求めましょう。出力にテスト電源vtをつなぐの。

め

四国めたん

流れ込む電流をitとするわ。入力の小信号は0、Vbも小信号ではグラウンドね。

め

四国めたん

M1はvgs1=0なので、電流源が消えて、ro1だけが残るわ。

め

四国めたん

itはM2を通って、すべてro1に流れる。だから、vx＝it·ro1ね。

め

四国めたん

M2のゲートと基板はグラウンド。だから、vgs2もvbs2も−vxになるの。

め

四国めたん

すると電流源は、上向きに(gm2+gmb2)vxを流そうとするわ。

ず

ずんだもん

上向きなのだ？itは下向きに流れているのだ。

め

四国めたん

そう。だからro2には、itに加えて、電流源の分も下向きに流れるの。

め

四国めたん

Routは、ro1+ro2に、(gm2+gmb2)ro2·ro1を足したもの。

め

四国めたん

最後の項がずっと大きいから、Rout≈(gm2+gmb2)ro2·ro1ね。

四国めたん：基板を無視すれば、ro1が、固有利得gm2·ro2倍になった形よ。

ず

ずんだもん

ソースに何がつながるかで、こんなに変わるのだ！

め

四国めたん

ええ。前回はソースが接地だったけれど、今回はM2のソースにro1がつながっているの。

四国めたん：VOUT=1.2 Vで、Routは約7.1MΩ。単体の約107 kΩの、約66倍よ。

め

四国めたん

四国めたん：それに、平らになり始めるのも、単体より右なの。これは後で効いてくるわ。

7カスコードカレントミラー 動画 4:15

ず

ずんだもん質問

第4回のカレントミラーの誤差も、これで小さくできるのだ？

め

四国めたん

8カスコード増幅回路 動画 4:52

め

四国めたん

増幅回路にも使いましょう。第4回の能動負荷を、上下ともカスコードにするの。

四国めたん：下はNMOSのM1とM2、上はPMOSのM3とM4。入力はM1のゲートよ。

め

四国めたん

PMOSはW/Lを2倍にして、VovをNMOSと同じ約0.3 Vにそろえたわ。

四国めたん：PMOSの基板は、それぞれのソースにつなぐわ。だから基板バイアス効果は出ないの。

め

四国めたん

利得は、−gm1×出力抵抗。出力抵抗は、下と上のカスコードの並列ね。

め

四国めたん

gmやroがそろい、基板効果を省くと、どちらも約gm·ro·ro。並列で半分ね。

四国めたん：だから、Av≈−(gm·ro)²/2になるわ。

ず

ずんだもん質問

固有利得の2乗なのだ！gm·ro≈70なら、約2500倍なのだ？

め

四国めたん

動作点のごく近くで計算すると、約−1400。グラフの傾きとも合うわ。

め

四国めたん

目安より小さいのは、各VDSが小さくてroが下がるから。あとで電圧の余裕と一緒に見るわ。

ず

ずんだもん

第4回の約−35の、約40倍なのだ！トランジスタを2つ足しただけなのだ。

ずんだもん

め

め

四国めたん

四国めたん

VDSが小さいと、roも下がるの。目安の約2500に届かなかったのは、そのためよ。

め

四国めたん

固有利得の小さい先端プロセスほど、電源電圧も低くて積みにくい。そこが悩みどころよ。
