第4回

カレントミラーと能動負荷

アナログ回路入門シリーズ第4回です。設計課題で、RDを大きくしたら増幅しなくなった……その理由と解決策を見ていきます。

直流では電流が決まっていて、小信号では抵抗が大きい負荷＝電流源をMOSFETで作ります。ダイオード接続とカレントミラー、roによる誤差と飽和の条件、PMOSを経て、PMOSのカレントミラーを負荷にした能動負荷のソース接地増幅回路を組み立て、回路図の変形から Av = −gm1(ro1∥ro2) を導きます。

4ダイオード接続で電流源を作る 動画 1:11

め

四国めたん

飽和領域のMOSFETは、VGSで電流が決まる電流源だったわね。

ず

ずんだもん質問

でも、欲しい電流になるVGSは、どうやって決めるのだ？

め

四国めたん

そこで、ゲートとドレインをつないでみましょう。これをダイオード接続と呼ぶの。

四国めたん：ここに、外から基準の電流Irefを流し込むわ。

め

四国めたん

するとMOSFETは、ちょうどIrefが流れるVGSを、自分で作るの。

ず

ずんだもん質問

ゲートとドレインをつないでも、飽和領域なのだ？

め

四国めたん

ええ。VDS=VGSだから、VGSがVthを超えていれば、飽和の条件は必ず成り立つのよ。

四国めたん：たとえばIref=0.1 mAなら、VGSは約0.70 Vになるわ。

5カレントミラー 動画 1:54

め

四国めたん

もう1つのMOSFETを並べて、ゲート同士をつないでみましょう。

め

四国めたん

同じ大きさで、同じVGS。だから、右にも同じ電流が流れるの。

四国めたん：鏡に映すようなので、カレントミラー。右の電流をIoutとするわ。

四国めたん：右のW/Lを2倍にすると、Ioutも2倍の0.2 mA。比で電流を決められるの。

め

四国めたん

IDはW/Lに比例するからよ。Vthなどがそろい、左右のVDSが等しいことが前提ね。

6roによる誤差と飽和の条件 動画 2:23

め

四国めたん

そうとは限らないわ。まず、右のW/Lを左と同じに戻して考えましょう。

め

四国めたん

左のVDSは約0.70 V。右のVDSは、つなぐ回路しだいで変わるでしょう？

四国めたん：右のVDSを1.5 Vにすると、Ioutは約0.107 mA。7%ほど多くなるわ。

四国めたん

め

四国めたん

右のVDSが小さすぎても困るの。0.2 Vだと飽和領域を外れて、Ioutは約0.080 mAよ。

四国めたん：だから右も飽和領域、今回はVDSが約0.3 V以上で使う必要があるの。

7PMOSをくわしく 動画 3:11

ず

ずんだもん質問

このミラーを、RDのところに入れれば完成なのだ？

め

四国めたん

負荷はVDDと出力の間。NMOSで作ると、ソースが出力側になってVGSが動いてしまうの。

め

四国めたん

そこで、第1回でちらっと見たPMOSを使うわ。ソースをVDD側に置けるの。

め

四国めたん

記号をおさらいしましょう。ソースの矢印が内向きで、ゲートに丸。ソースが上ね。

め

四国めたん

第1回のとおり、ゲートをソースより低くするとオン。だから電圧はVSGで考えるの。

四国めたん：VSGが|Vth|を超えると、電流はソースからドレインへ、上から下に流れるの。

四国めたん：式はNMOSと同じ形。VSGとVSD、|Vth|で書き、電流はSからDを正にとるの。

ず

ずんだもん質問

大きさも、NMOSとまったく同じなのだ？

め

四国めたん

正孔は電子より動きにくいの。このモデルでは、同じW/LでKを半分にするわ。

め

四国めたん

PMOSでもカレントミラーは作れるわ。NMOSのミラーを、上下に裏返した形ね。

8能動負荷のソース接地増幅回路 動画 4:13

め

四国めたん

では、PMOSのミラーを負荷にしましょう。トランジスタの負荷を、能動負荷と呼ぶの。

め

四国めたん

下のM1が増幅するNMOS。上のM2が負荷で、M3がIrefを受けるダイオード接続よ。

四国めたん：VDD=1.8 V、Iref=0.1 mA。M2とM3は同じ大きさ。基板はどれもソースにつなぐわ。

め

四国めたん

VOUTは、M1とM2の電流が等しくなる点で決まるの。2つの特性を重ねましょう。

ず

ずんだもん

2本の曲線の交点が、動作点なのだ！

め

四国めたん

VOUTを0.9 Vにするには、VINは約0.70 V。電流は約0.1 mAよ。

四国めたん：VINを動かすと、VOUTはこう変わるわ。第3回より、ずっと急でしょう？

9小信号回路図への変形と Av 動画 4:58

め

四国めたん

利得を求めましょう。第3回と同じ手順で、回路図を変形していくわ。

四国めたん：前提として、M1もM2も飽和領域よ。出力が約0.3〜1.4 Vの間ならそうなるわ。

め

四国めたん

手順1。VDDとVINの直流分は短絡。Irefの電流源は開放ね。

ず

ずんだもん質問

Irefを開放したら、M2のゲートは浮いてしまわないのだ？

め

四国めたん

M3は小信号では、約1/gm3の抵抗でゲートをグラウンドにつなぐの。

め

四国めたん

そこへ信号は入らないから、ゲートの小信号は0。vsg2=0ね。

四国めたん：手順2。M2の小信号モデルは、gm2·vsg2=0なので、ro2だけが残るの。

ず

ずんだもん

電流源の負荷は、小信号ではro2という抵抗に見えるのだ！

め

四国めたん

M1は第3回と同じ。gm1·vinの電流源と、ro1の並列ね。

四国めたん：手順3。ro1もro2も、出力とグラウンドの間にあるから、並列よ。

め

四国めたん

RDがro2に変わっただけ。Av＝−gm1(ro1∥ro2)になるわ。

10固有利得との関係と数値例 動画 6:08

ず

ずんだもん質問

理想電流源のときのgm·roと比べると、どうなのだ？

め

四国めたん

ro1=ro2なら、並列の値はroの半分。だからAv＝−gm·ro/2ね。

め

四国めたん

め

四国めたん

数値では、gm1は約0.65 mA/V。ro1とro2は、どちらも約108 kΩよ。

四国めたん：並列で約54 kΩ、Avは約−35。gm1·ro1の約70の、ちょうど半分ね。

ず

ずんだもん

グラフの傾きとも合うのだ。第3回の約−4の、約9倍なのだ！

め

四国めたん

バイアスも前回と違う例よ。Vovが約0.3 Vに下がって、固有利得も約70に増えたの。
