第5回

ソースフォロワとゲート接地：3つの基本増幅回路

アナログ回路入門シリーズ第5回です。増幅回路に負荷をつないだら利得が激減……その対策として、ソースフォロワとゲート接地を見ていきます。

どの端子に入れてどの端子から出すかで、増幅回路の性質は大きく変わります。ソースフォロワの大信号特性と小信号利得（基板バイアス効果で1より下がる理由）、出力抵抗≈1/gmとバッファとしての役割、ゲート接地の入力抵抗と利得を、回路図の変形とテスト電源で求め、3つの基本増幅回路を比較表にまとめます。

3ソースフォロワ：大信号特性 動画 0:54

め

四国めたん

まずソースフォロワ。ドレインはVDD、ソースから電流源で電流を引き抜くの。

め

四国めたん

ただし計算では理想電流源として、その出力抵抗は無限大にするわ。

め

四国めたん

電流が決まるから、VGSもほぼ決まる。だからVOUT=VIN−VGSね。

ず

ずんだもん

グラフにすると、VOUTがVINの少し下をついてくるのだ！

め

四国めたん

出力が入力に追従するから、フォロワ。VIN=1.2 VならVOUTは約0.42 Vよ。

め

四国めたん

直流ではVGSの約0.78 Vだけ下がる。でも、変化はほぼそのまま伝わるの。

ず

ずんだもん質問

4ソースフォロワ：小信号と利得（基板バイアス効果） 動画 1:47

め

四国めたん

手順1。VDDは短絡、電流源は開放。ドレインは小信号ではグラウンドね。

め

四国めたん

手順2。MOSFETを、小信号モデルに置き換えるわ。

め

四国めたん

ゲートはvin、ソースはvout。だから、vgs=vin−voutね。

四国めたん：手順3。出力のKCLを解くと、Av=gm/(gm+1/ro)。約0.99よ。

ず

ずんだもん質問

グラフは0.83だったのだ。何が足りないのだ？

め

四国めたん

第2回の基板バイアス効果よ。基板はグラウンド、ソースはVOUTだから、VSB=VOUTね。

四国めたん：出力が上がるとVthも上がり、電流が減る。だから、出力の上がり方が鈍るのよ。

め

四国めたん

小信号では、gmb·vbsの電流源を足すの。ここではvbs＝−voutね。

め

四国めたん

gmbは基板の相互コンダクタンス。gmは約0.66 mA/V、gmbはその約2割よ。

め

四国めたん

Av=gm/(gm+gmb+1/ro)。gmbの分下がって約0.83、グラフと合うわ。

め

四国めたん

基板をソースにつなげば約0.99に戻るわ。でも普通のNMOSは、基板が共通なの。

ず

ずんだもん

第2回の基板バイアス効果が、ここで効いてくるのだ！

5ソースフォロワの出力抵抗 動画 3:08

ず

ずんだもん質問

でも、利得が1より小さいなら、何に使うのだ？

め

四国めたん

カギは出力抵抗よ。出力にテスト電源vxをつないで、流れ込む電流ixを求めましょう。

め

四国めたん

入力の小信号は0にするわ。するとvgsもvbsも、−vxになるの。

四国めたん：ix＝(gm+gmb+1/ro)vx。電流がvxに比例して、係数はさっきの分母と同じよ。

ず

ずんだもん

電流源なのに、抵抗みたいにふるまうのだ！

め

四国めたん

そう。出力抵抗はその逆数で、基板効果まで入れて約1.3 kΩよ。

め

四国めたん

gmbとroを省くと、およそ1/gmで約1.5 kΩ。これが簡単な目安ね。

四国めたん：第3回のソース接地の出力抵抗、約4.6 kΩより、ずっと小さいわね。

6バッファとしての役割 動画 3:55

ず

ずんだもん質問

出力抵抗が小さいと、何がうれしいのだ？

め

四国めたん

増幅回路の出力は、小信号では、Av·vinの電圧源とRoutの直列で表せるわ。

め

四国めたん

信号だけが流れる負荷RLをつなぐと、出力はRoutとRLで分圧されるの。

め

四国めたん

第4回の能動負荷の回路は、Av約−35、Rout約54 kΩ。RL=10 kΩをつなぐと…

ず

ずんだもん

利得が約−5.5まで下がったのだ！ボクの実験と同じなのだ。

め

四国めたん

そこで、間にソースフォロワを入れるの。ゲートに電流は流れないから、前の段は約−35のままよ。

め

四国めたん

ただし、段の間の直流の電位はそろえてあるとして、小信号だけを見るわ。

四国めたん：そのまま直結すると、フォロワの出力は約0.17 Vで、電流源の余裕が足りないのよ。

四国めたん：出力抵抗は約1.3 kΩ。フォロワの0.83倍を掛けても、全体で約−26よ。

め

四国めたん

こうして間に入って負荷を動かす回路を、バッファと呼ぶの。フォロワの大事な役目よ。

7ゲート接地 動画 5:03

め

四国めたん

3つ目はゲート接地。第3回のソース接地と、同じ素子・同じバイアスで比べるわ。

め

四国めたん

ゲートは直流0.8 Vに固定。入力vinはソースに入れて、出力はドレインからとるの。

四国めたん：ソースの直流は0 V。だから動作点は第3回と同じで、VOUTは約0.92 Vよ。

ず

ずんだもん質問

ソースの電圧を上げると、出力はどうなるのだ？

め

四国めたん

VGSと電流が減るから、VOUTは上がるの。ソース接地と逆で、入力と同じ向きね。

め

四国めたん

小信号ではvgs＝−vin。基板とroを無視すると、Av＝＋gm·RDになるわ。

め

四国めたん

ここでもソースが動くので、gmbが効くの。今度はgmに足されて、利得を上げるのよ。

め

四国めたん

roも入れると、Av＝(gm+gmb+1/ro)(RD∥ro)。約＋5.1よ。

ず

ずんだもん質問

ソースに入れると、入力に電流が流れ込むのだ？

め

四国めたん

ええ。入力抵抗はRin≈1/(gm+gmb)、約1 kΩ。フォロワの出力抵抗と同じ形ね。

四国めたん：入力抵抗が小さいから、電流として入ってくる信号を受け取るのが得意なの。

め

四国めたん

入力を理想電圧源でつなぐと、出力抵抗はソース接地と同じRD∥ro、約4.6 kΩよ。
