3差動対の回路 動画 0:50

め

四国めたん

同じNMOSのM1とM2を並べて、ソースどうしをつなぐの。この点をPと呼ぶわ。

め

四国めたん

Pから一定の電流ISSを引き抜くの。この電流源を、尾電流源と呼ぶわ。

め

四国めたん

ドレインにはRD。入力はVIN1・VIN2、出力はVOUT1・VOUT2よ。

め

四国めたん

VDD=1.8 V、ISS=0.2 mA、RD=5 kΩ。入力の直流は、どちらも1.3 Vよ。

め

四国めたん

基板はグラウンド。Pは約0.49 Vなので、基板バイアス効果も入れて解くわ。

め

四国めたん

2つの入力が等しければ、左右対称。電流は半分ずつ、0.1 mAね。

4大信号特性 動画 1:30

ず

ずんだもん質問

入力に差をつけると、どうなるのだ？

め

四国めたん

Pで電流を足すと、ID1+ID2=ISS。合計は、いつも0.2 mAなの。

め

四国めたん

VIN1を上げるとM1の電流が増えて、そのぶん、M2の電流が減るのよ。

め

四国めたん

入力の差ΔVinを横軸に、電流の差ΔIDを描くと、こうなるわ。

め

四国めたん

0の近くは、ほぼ直線。傾きは約gmで、両側の変化が足し合わさっているの。

め

四国めたん

差が大きくなると、M2はほぼオフ。電流のほとんどがM1に流れるの。

め

四国めたん

二乗則なら、片側がオフになる目安は√2·Vov、約0.43 Vよ。

め

四国めたん

Vovは釣り合ったときの約0.30 V。このモデルでは0.43 Vでも、少し電流が残るわ。

ず

ずんだもん

差が大きいと、電流を左右に切り替えるスイッチになるのだ！

め

四国めたん

逆に、2つの入力を一緒に動かすと、Pがついて動くだけ。電流は半分ずつのままよ。

5差動信号と同相信号 動画 2:32

め

四国めたん

ここからは小信号。2つの入力vin1とvin2を、2つの成分に分けるの。

め

四国めたん

差動信号vid=vin1−vin2、同相信号vic＝(vin1+vin2)/2よ。

四国めたん：逆に、vin1=vic+vid/2、vin2=vic−vid/2と書けるの。

ず

ずんだもん

線形回路だから、重ね合わせで、別々に解けばいいのだ！

6差動の半回路と差動利得 動画 2:57

め

四国めたん

まず差動だけ。M1のゲートには＋vid/2、M2のゲートには−vid/2が入るわ。

め

四国めたん

左右対称で、入力は逆向きの小信号。Pを動かす作用が打ち消し合って、Pの小信号は0なの。

め

四国めたん

小信号で見ると、Pはグラウンドと同じ。これを仮想接地と呼ぶわ。

め

四国めたん

左半分を取り出すと、第3回のソース接地そのもの。これが差動の半回路よ。

め

四国めたん

ソースが動かないので、基板バイアス効果の項も出てこないわ。

め

四国めたん

vout1＝−gm(RD∥ro)·vid/2。vout2は符号が逆だから、差は2倍ね。

め

四国めたん

出力の差で見た差動利得は約−3.1。式はAdm＝−gm(RD∥ro)で、大信号と合うわ。

ず

ずんだもん

入力が半分ずつでも、差をとれば、ソース接地1個分の利得なのだ！

7同相の半回路と同相利得 動画 3:50

め

四国めたん

次は同相。両方のゲートに同じvicを入れて、片側の出力で利得を求めるわ。

め

四国めたん

尾電流源が理想なら、電流は変わらない。出力も動かないから、Acm=0ね。

め

四国めたん

でも本物の尾電流源は、第4回のミラー。出力抵抗RSSを持つの。

め

四国めたん

W/Lを2倍にして0.2 mAを流すと、RSSは約47 kΩよ。

め

四国めたん

RSSを、2RSSの2本の並列に分けるわ。対称だから、間の線には電流が流れないの。

め

四国めたん

線を切ると、ソースに2RSSがついたソース接地。これが同相の半回路よ。

ず

ずんだもん質問

ソースに抵抗があると、どうなるのだ？

め

四国めたん

基板を無視すると、ソースが入力についていき、電流はvic/(2RSS)だけ変わるの。

め

四国めたん

だから、Acm≈−RD/(2RSS)。基板の分も入れると、約−0.044よ。

め

四国めたん

両方の出力が同じだけ動くから、出力の差をとれば、ちゃんと消えるわ。

8CMRR 動画 4:55

め

四国めたん

差動利得と同相利得を同じ出力で測った比を、CMRR、同相除去比と呼ぶの。

四国めたん：片側の出力で比べると、差動利得は半分の約1.5。CMRRは約35倍ね。

め

四国めたん

基板効果を省いた目安は、CMRR≈gm·RSS。尾電流源の出力抵抗で決まるのよ。

め

四国めたん

もっと大きくするなら、RSSを大きくする。第6回のカスコード電流源の出番ね。

め

四国めたん

ただし、尾電流源が電圧の余裕を使うぶん、入力の直流を高くする必要があるわ。

9能動負荷の差動対 動画 5:31

ず

ずんだもん質問

次の回路に、出力を1本で渡したいときは、どうするのだ？

め

四国めたん

片側だけでは利得が半分。そこで、第4回のPMOSミラーを負荷にするの。

め

四国めたん

M3がM1の電流を受けて、M4が写すの。出力はM2とM4のドレインよ。

め

四国めたん

素子がそろって入力が等しいと、両側のドレインは、どちらも約0.97 Vになるの。

め

四国めたん

vidでM1の電流が増えると、M4がそれを写して、出力に電流を押し込むわ。

め

四国めたん

同時に、M2が引き抜く電流は減る。どちらも、出力を上げる向きに働くの。

め

四国めたん

左右の電流の変化が、1本の出力に集まる。シングルエンド出力への変換よ。

め

四国めたん

出力抵抗はro2∥ro4。だから、利得はAv≈gm(ro2∥ro4)になるわ。

ず

ずんだもん

第4回の能動負荷と、同じ形なのだ！

め

四国めたん

ええ。ただ第4回と違って、今回は非反転。VIN1が上がると出力も上がるの。

め

四国めたん

利得は約＋31。抵抗負荷で出力の差をとった場合の、約10倍よ。

め

四国めたん

同相の変化はミラーで打ち消し合うの。入力が0.1 V一緒に動いても、出力は約2 mVよ。

ず

ずんだもん質問

第4回の、動作点がずれやすい問題も、これで解決なのだ？

め

四国めたん

同相のずれには強くなるわ。でも入力の直流は、約1.07〜1.50 Vの範囲に置く必要があるの。

四国めたん：低い側では尾電流源の余裕が減って、RSSも下がるわ。

め

四国めたん

2つの入力の差には敏感なまま。そこは後で学ぶ負帰還でそろえるの。
