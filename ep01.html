第1回

MOSFETのしくみと特性カーブ

アナログ回路入門シリーズ第1回です。電子回路の単位がピンチのずんだもんと一緒に、トランジスタのしくみを基礎から見ていきます。

今のICのトランジスタは、ほとんどがCMOSという方式で作られたMOSFETです。まずバイポーラトランジスタとMOSFETの動作原理を比べ、断面図で「なぜ電流が流れるのか」（反転層・チャネル）を確かめます。測定回路と特性カーブから、遮断（サブスレッショルド）・線形・飽和の3つの動作領域と、電圧制御電流源として働く条件を解説。最後にPMOSと組み合わせたCMOSインバータまで扱います。

3バイポーラとMOSFETの違い 動画 0:40

め

四国めたん

左がnpn型のBJT、右がNチャネルMOSFETの記号よ。

ず

ずんだもん質問

どっちも電流を流す部品なのに、何が違うのだ？

め

四国めたん

BJTでは、ベースとエミッタの間のpn接合に、順方向の電圧VBEをかけるの。

め

四国めたん

そして、コレクタはベースより高い電位にしておくわ。

四国めたん：するとエミッタから電子が注入され、その多くが薄いベースを抜けて、コレクタへ進むの。

め

四国めたん

コレクタ電流ICはVBEで指数関数的に決まる。ベースにも少し電流が流れるわ。

め

四国めたん

一方MOSFETは、ゲートの電圧で、表面に電子の通り道を作るの。

ず

ずんだもん質問

ゲートからは、電流が流れ込むのだ？

め

四国めたん

ゲートは薄い絶縁膜で隔てられているから、直流の電流はほとんど流れないのよ。

四国めたん：違いを表にまとめると、こうなるわ。

め

四国めたん

このシリーズは、MOSFETが中心よ。今日は、そのしくみを見ていきましょう。

ず

ずんだもん

よろしくなのだ！

四国めたん

VGSと、ドレイン・ソース間電圧VDSを与えて、IDを見る回路よ。

5なぜ電流が流れる？ 断面で見るチャネル 動画 2:22

め

四国めたん

断面を見てみましょう。p型の基板に、n型のソースとドレインがあるの。

四国めたん：その上に、薄い酸化膜をはさんでゲートがのっているのよ。

め

四国めたん

n+のソースとドレインには電子が、p型の基板には正孔がたくさんあるの。

四国めたん：正孔は、電子が抜けた穴が、正の電荷のように動くものよ。

ず

ずんだもん質問

ソースとドレインの間はp型だから、電子は通れないのだ？

め

四国めたん

そう。境目のpn接合は、電子にとってはエネルギーの山。越えにくい壁なの。

四国めたん：だから、VGSが小さいうちは電流はほとんど流れない。これが遮断領域よ。

め

四国めたん

ゲートに正の電圧をかけると、まず表面の正孔が押しのけられるの。

四国めたん：動ける電荷が少なくなったこの部分を、空乏層と呼ぶわ。

め

四国めたん

さらに上げると、表面に電子が集まって山が低くなり、ソースとドレインがつながるの。

め

四国めたん

この電子の通り道をチャネル、または反転層と呼ぶの。

四国めたん：チャネルができ始めるVGSが、しきい値電圧Vthよ。

ず

ずんだもん質問

通り道ができたら、電子はどっちへ流れるのだ？

め

四国めたん

VDSをかけると、電子は電界に押されて、ソースからドレインへ流れるの。

四国めたん：電子の電荷は負だから、電流の向きは逆。IDはドレインからソースへ流れるわ。

ず

ずんだもん質問

VGSをもっと上げると、チャネルが太くなるのだ？

め

四国めたん

ええ。電子が増えるほど、電流が流れやすくなるのよ。

め

四国めたん

VDSを一定にして、VGSとIDの関係をグラフにするとこうなるわ。

ず

ずんだもん

Vthまではほぼゼロで、そこから増え始めるのだ！

め

四国めたん

しきい値より十分上では、IDはVGS−Vthの2乗にほぼ比例するの。

ず

ずんだもん質問

VGS−Vthって、しきい値をどれだけ超えたかなのだ？

め

四国めたん

そうよ。オーバードライブ電圧Vovと呼ぶ、とても大事な量ね。

7サブスレッショルド領域 動画 4:10

ず

ずんだもん質問

ところで、Vthより下だと、電流は本当にゼロなのだ？

め

四国めたん

さっきは遮断と言ったけど、実はゼロではないの。縦軸を対数にしてみましょう。

四国めたん：Vthより下でも、IDはVGSに対して指数関数的に流れているの。

め

四国めたん

これをサブスレッショルド領域、または弱反転領域と呼ぶわ。

四国めたん：このモデルでは、VGSが約90 mV変わるごとに、電流が1桁変わるの。

め

四国めたん

普通のMOSFETでは、常温で1桁あたり約60 mVより急にはならないのよ。

ず

ずんだもん質問

ゼロじゃないなら、オフでも電流が漏れているのだ？

め

四国めたん

そう。チップに何十億個も並ぶと、無視できない漏れ電流になるの。

四国めたん：逆に、この小さな電流をあえて使う、超低消費電力の回路もあるのよ。

8ID–VDS特性と線形領域 動画 4:57

め

四国めたん

Vthより上に戻りましょう。今度はVGSを固定して、VDSを変えてみるわ。

ず

ずんだもん

9ピンチオフ 動画 5:24

ず

ずんだもん質問

じゃあ、どうして途中から平らになるのだ？

め

四国めたん

VDSを上げると、ドレイン側ではゲートとの電圧差VGDが小さくなるの。

四国めたん：だから、チャネルはドレインに近いほど細くなるのよ。

四国めたん：VGDがVthを下回ると、ドレイン端でチャネルが消えてしまうの。

四国めたん：これをピンチオフと呼ぶわ。

ず

ずんだもん質問

チャネルが途切れたら、電流は止まっちゃうのだ？

め

四国めたん

止まらないわ。電子は途切れた部分を、強い電界で一気に運ばれるの。

四国めたん：電流の大きさは、チャネルの部分でほぼ決まる。だから平らになるのよ。

10飽和領域と電圧制御電流源 動画 5:57

め

四国めたん

グラフに戻りましょう。VGSを変えて何本か描くとこうなるわ。

四国めたん：境目はVDS=VGS−Vth。点線の左が線形領域、右が飽和領域ね。

ず

ずんだもん

飽和領域だと、VDSを変えても電流がほとんど変わらないのだ。

め

四国めたん

しかもIDの大きさはVGSで決まる。これがさっきの電圧制御電流源よ。

ず

ずんだもん質問

だから増幅回路では、飽和領域で使うのだ？

め

四国めたん

その通り。増幅回路の話は、また今度じっくりやりましょう。

四国めたん：ただ、よく見ると少しだけ右上がりでしょう？これがチャネル長変調よ。

ず

ずんだもん

完全な電流源ではないのだ。

め

四国めたん

ええ。これは次回くわしく見ましょう。

12PMOSとCMOSインバータ 動画 6:53

ず

ずんだもん質問

そういえば、最初に出てきたCMOSって、結局なんなのだ？

め

四国めたん

そのために、もう1つのMOSFET、PチャネルのPMOSを紹介するわ。

四国めたん：CMOSでは、p型基板の中のnウェルにPMOSを作るの。nとpがNMOSと逆ね。

め

四国めたん

ゲートをソースより十分低くすると、表面に正孔が集まって通り道ができるの。

四国めたん：記号はゲートに丸を付けて区別するの。ソースを上に描くことが多いわ。

め

四国めたん

PMOSを上、NMOSを下に置いて、上のソースを電源VDDに、下のソースを接地につなぐわ。

め

四国めたん

ゲート同士をつないで入力に、ドレイン同士をつないだ点を出力にするの。

四国めたん：入力が0 VならPMOSがオン、NMOSはオフ。出力はVDDにつながるわ。

め

四国めたん

入力をVDDにすると逆。NMOSがオンになって、出力は0 Vになるの。

ず

ずんだもん

入力と出力が、いつも反対になるのだ！

め

四国めたん

ええ。これがインバータ。論理回路のNOTね。

め

四国めたん

VDD=1.8 Vで、入力を0からVDDまで変えると、出力はこう変わるわ。

め

四国めたん

この例では、入力がVDDの半分の0.9 V付近で、出力が急に切り替わるの。

め

四国めたん

NMOSとPMOSが、互いを補い合って動く。だから相補型MOS、CMOSと呼ぶの。

ず

ずんだもん質問

片方がオフになると、何がうれしいのだ？

め

四国めたん

入力が0かVDDで止まっているときは、どちらかが必ずオフ。電流がほとんど流れないの。

四国めたん：だから消費電力が小さい。今のICのほとんどがCMOSなのは、このためよ。

ず

ずんだもん

最初の「今のICはCMOS」の意味が、やっとわかったのだ！
