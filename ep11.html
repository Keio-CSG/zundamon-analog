ずんだもんと学ぶアナログ回路

第11回

周波数特性②：極・零点と多段回路

アナログ回路入門シリーズ第11回。回路図を見て、周波数特性の「極」と「零点」を読む方法を学び、オペアンプを2段にすると発振する理由まで見ます。

容量のインピーダンス1/(sC)からRCローパスの伝達関数を作り、分母が0になる点（極）をs平面に描いて、ボード線図（−20dB/dec、位相−45°→−90°）と対応させます。分子が0になる点（零点）も同じ見方で押さえます。

回路図からは、ノードごとの抵抗×容量（時定数）で極を見積もります。ソース接地回路のボード線図を、2つの極と右半平面零点を足して手で描き、帯域を決める主極（ドミナントポール）を時定数の和で求めます。

Cgdが極を押し広げる「極の分離（ポールスプリット）」を、極と零点が動く様子で確認します。

次に第4回の能動負荷の帯域を調べ、時定数が近いときは和で見積もる理由を見ます。第4回の回路を2つ並べた約1200倍の2段アンプでは、極は3つになります。

最後に、帰還をかけたときのループ利得T＝βAと、位相が−180°になる周波数で|T|が1以上だと発振することを、ボード線図と時間波形で確認します。位相余裕と、主極を下げる補償容量の考え方（入口）までが今回の範囲です。

第10回の周波数特性①の続きで、次回はSKY130での実際のオペアンプ設計へつなぎます。

3極とは：伝達関数とs平面

め

四国めたん

ラプラス変換では、容量のインピーダンスは1/(sC)になるわ。

四国めたん：s＝jωと置けば、前回の1/(jωC)ね。

め

四国めたん

出力を入力で割った比を、伝達関数と呼ぶわ。RSとCgsの分圧なら、H(s)＝1/(1＋sRSCgs)ね。

四国めたん：注目するのは分母よ。分母が0になるsを、極と呼ぶの。

め

四国めたん

分母1＋sRSCgs＝0を解くと、s＝−1/(RSCgs)。ωp＝1/(RSCgs)と置けば、極はs＝−ωpの点ね。

四国めたん：sは複素数だから、平面に描けるわ。横軸が実部σ、縦軸がjω。これがs平面よ。

四国めたん：極は×で描くの。この極は負の実軸の上、−ωpの点。左半平面にあるわ。

ず

ずんだもん質問

分母が0って、割り算できないのだ！そんな点があって大丈夫なのだ？

め

四国めたん

正弦波のsは、縦のjω軸の上だけを動くの。だから左にある極には届かないわ。

め

四国めたん

でも極の近くを通ると、利得と位相が大きく変わるの。

め

四国めたん

ωpを2πで割った値を、極の周波数と呼ぶわ。この極は約3.8GHzね。

ず

ずんだもん

3.8GHz！前回のカットオフ周波数と、同じなのだ！

め

四国めたん

そうよ。極が1つなら、極の周波数がカットオフ周波数になるの。

4ボード線図で極と零点を読む

め

四国めたん

前回のボード線図で、極を読みましょう。極の周波数までは、利得はほぼ平らよ。

め

四国めたん

極の周波数から先は、利得が−20dB/decで下がるの。

四国めたん：decは10倍のこと。10倍ごとに、20dB下がるのよ。

四国めたん：位相は、極の周波数で−45°。十分高いと、−90°に近づくわ。

め

四国めたん

次は分子よ。分子が0になるsは、零点と呼ぶわ。s平面では○で描くの。

ず

ずんだもん質問

零点は、極と逆の働きなのだ？

め

四国めたん

そうよ。左半平面の零点は、＋20dB/decで利得が上がり、位相は最大90°進むの。

四国めたん：伝達関数は因子のかけ算。大きさはdBにすると足し算になり、位相も各因子の和になるの。

め

四国めたん

極と零点が1つずつなら、−20と＋20で傾きが打ち消し合って、また平らになるわ。

5回路図から極を読む

め

四国めたん

実は、回路図を見るだけで、極が読めるの。ノードごとに、見える抵抗と容量を探すのよ。

ず

ずんだもん質問

ノードって、どの点のことなのだ？

め

四国めたん

配線でつながった1つの点よ。ソース接地なら、ゲートとドレインの2つね。

四国めたん：この回路では、容量は3つあるけど、ノードは2つだから、極は2つよ。

四国めたん：ノードごとに、そのノードから見える抵抗×容量が時定数。極の周波数は、1/(2π×時定数)で見積もれるわ。

め

四国めたん

入力ノードは、抵抗がRS=10 kΩ、容量はCgsとミラー容量を合わせて約8.2fF。約82psで、約1.9GHzの極ね。

め

四国めたん

出力ノードは、抵抗が約4.6 kΩ、容量が約2.8fF。約13psで、約12GHzの極ね。

め

四国めたん

数値で解くと、極は約1.8GHzと約23GHz。低いほうはほぼ合って、高いほうは目安ね。

ず

ずんだもん質問

高いほうは、ずいぶんずれたのだ？

め

四国めたん

そうね。でも帯域を決めるのは低いほう。ずれる理由は、あとの「極の分離」で分かるわ。

6手で描く：極・零点を足していく（右半平面零点）

め

四国めたん

読み取った極と零点で、ボード線図を描きましょう。低い周波数の利得は約12dBよ。

め

四国めたん

1つ目の極、約1.8GHzから、−20dB/decで下がるの。

四国めたん：位相は、−45°から−90°へ向かうわ。

四国めたん：2つ目の極、約23GHzから、−40dB/decで下がるの。

め

四国めたん

位相は、さらに−180°へ向かうわ。

四国めたん：零点ができるのは、ゲートから出力へ信号の道が2本あるからよ。Cgdを通る道と、gm·vgの電流の道ね。

ず

ずんだもん質問

道が2本あると、どうして零点ができるのだ？

め

四国めたん

2つの道の電流が打ち消し合うと、出力は0になるわ。それがs＝gm/Cgdのときよ。

ず

ずんだもん

sがプラスの実数なのだ？s平面の右側なのだ！

め

四国めたん

そう、右半平面零点よ。位置を周波数で表すと、gm/(2πCgd)で約173GHzね。

め

四国めたん

jω軸の上ではないから、173GHzの正弦波で出力が0になるわけではないわ。

ず

ずんだもん質問

右側にあると、左側の零点と何がちがうのだ？

め

四国めたん

傾きは左半平面の零点と同じ＋20dB/dec。でも位相は、極と同じように遅れるの。

ず

ずんだもん

利得は上向きなのに、位相は遅れるのだ？いいところがないのだ！

め

四国めたん

この回路では173GHzと十分高いから、帯域の近くでは、ほとんど効かないわ。

め

四国めたん

前回、−3dBの点で約50°遅れたわね。内訳は、極が約45°と約4.5°、零点が約0.6°よ。

ず

ずんだもん

45°より多かった分は、2つ目の極と零点だったのだ！

7主極と時定数の和

ず

ずんだもん質問

帯域を決める低いほうの極は、もっと正確に手で見積もれないのだ？

め

四国めたん

分母を1＋bs＋as²と書くと、b＝1/ωp1＋1/ωp2になるの。ωp1は低いほうの極よ。2つの極が十分離れていれば、bはほぼ1/ωp1ね。

め

四国めたん

つまり、bが分かれば、低いほうの極ωp1がほぼ分かるの。

四国めたん：そしてbは、各ノードの抵抗と容量の積、つまり時定数の和になっているの。

め

四国めたん

入力ノードは、ミラー容量で約82ps。出力ノードは約13ps。和は約95psね。

め

四国めたん

1/(2π×95ps)で、約1.7GHz。数値で求めた極の1.8GHzに近いわ。

四国めたん：前回の入力ノードだけの見積もり約1.9GHzは少し高め。和で見積もった1.7GHzは、本物の極より必ず少し低めに出るの。本物はその間よ。

ず

ずんだもん質問

主極って、何が主なのだ？

め

四国めたん

いちばん低く、利得を最初に折り曲げる極よ。帯域をほぼ決める主極、ドミナントポールね。

8極の分離（ポールスプリット）

め

四国めたん

Cgdを外すと、極は約3.8GHzと約17GHzよ。

め

四国めたん

Cgdを外した回路の帯域は、前回見たとおり約3.6GHz。これは極ではなく帯域で、第2の極も少し効くぶん、極の3.8GHzより低いの。

四国めたん：Cgdを入れると、極は約1.8GHzと約23GHzになるわ。

ず

ずんだもん

低い極は下がって、高い極は上がったのだ！離れていくのだ！

め

四国めたん

入力と出力をつなぐ容量で、極が押し広げられる。これを極の分離、ポールスプリットと呼ぶわ。

め

四国めたん

Cgdに当たる容量を0から6.4fFまで増やすと、低い極は約3.8GHzから0.4GHzまで下がり、高い極は約17GHzから28GHzまで上がるの。右半平面零点も約22GHzまで近づいてくるわ。

ず

ずんだもん質問

どうして、低い極は下がって、高い極は上がるのだ？

め

四国めたん

入力側の極は、ミラー効果で容量が大きく見えるから、下がるの。

め

四国めたん

出力側では、Cgdを通して、ゲートが出力の動きに少しだけついていくの。

め

四国めたん

するとgmの電流が、出力の変化を打ち消して、見える抵抗が約2.8 kΩに下がるの。

四国めたん：極が上がるのは、そのせいよ。

9能動負荷の帯域

め

四国めたん

前回の最後に出た、第4回の能動負荷を見ましょう。利得は約35倍、出力の抵抗は約54 kΩよ。

め

四国めたん

出力には、負荷M2のCdbとCgdも加わるわ。PMOSの容量はNMOSと同じ値とし、M2のゲートは交流的にはグラウンドと見なすの。

め

四国めたん

入力ノードは、ミラー容量が大きくて約330ps。出力ノードも、抵抗が大きくて約300psよ。

ず

ずんだもん

2つのノードの時定数が、同じくらいなのだ！

め

四国めたん

だから、大きいほうだけでは決まらないの。和の約630psで見積もると、約250MHzよ。

四国めたん：前回の「飛び抜けて大きい時定数が決める」は、和がほぼ大きいほうに等しい、特別な場合ね。

め

四国めたん

数値で解くと、帯域は約260MHz。第10回の1.8GHzの、約7分の1よ。

め

四国めたん

時定数は近いのに、Cgdの極の分離で、極は約260MHzと約6.6GHzに離れるの。

め

四国めたん

利得のために出力の抵抗を大きくすると、時定数の和も増えて、主極が下がるのね。

102段アンプの極

ず

ずんだもん質問

もっとオペアンプの利得が欲しいときは、どうするのだ？

め

四国めたん

段を足して、掛け算で稼ぐの。第4回の回路を2つ並べると、約35×35で約1200倍よ。

ず

ずんだもん

1200倍なのだ！…でもボクの回路は、これで発振したのだ。

め

四国めたん

第5回のバッファと同じく、段の間の直流はそろえてあるとして、小信号だけを見るわ。

四国めたん：容量のつながったノードが3つだから、極も3つあるわ。

め

四国めたん

段の間のノードには、1段目の出力の容量が約5.6fF、2段目のCgsが4.2fF、2段目のミラー容量が約29fF。合わせて約39fFで、54 kΩとの時定数は約2.1nsにもなるの。

め

四国めたん

ほかのノードも足すと約2.7ns。見積もりは約58MHzで、数値で解くと約61MHzよ。

め

四国めたん

第8回で1つの極で近似したのは、この段の間のノードの主極よ。

四国めたん：極は3つ。約62MHz、約1.4GHz、約5.6GHzよ。ボード線図に1つずつ足していくと、傾きが−20、−40、−60dB/decと急になっていくわ。

め

四国めたん

3つの極の遅れが重なって、位相は約2.7GHzで−180°に達するわ。そこでも利得は約11倍、21dBもあるの。

四国めたん：極が増えるたびに、位相の遅れも増えるの。1つで最大90°、3つなら最大270°ね。

11帰還をかけると、なぜ発振するのか（入口）

ず

ずんだもん質問

位相が180°遅れると、何が困るのだ？

め

四国めたん

オペアンプに帰還をかけた回路よ。出力のβ倍が入力側へ戻り、入力との差が増幅されるの。

め

四国めたん

回路を一周したときの利得を、ループ利得Tと呼ぶわ。T＝βAよ。くわしい式は第13回ね。

め

四国めたん

低い周波数では、戻った信号は入力を打ち消す向き。出力の変動が抑えられるわ。これが負帰還ね。

め

四国めたん

でも位相が180°遅れると、符号が逆になるの。戻った信号が、入力と同じ向きに足されてしまうわ。

ず

ずんだもん

打ち消すはずの信号が、逆に足されちゃうのだ！

め

四国めたん

−180°では、一周するたびに信号が|T|倍。|T|が1より大きいと、ふくらみ続けるわ。

め

四国めたん

だから安定の条件は、位相が−180°になる周波数で、|T|が1より小さいことよ。

め

四国めたん

ボード線図で見ましょう。目安は、T＝1の周波数が−180°の周波数より低ければ、安定よ。

め

四国めたん

利得1倍のバッファはβ＝1で、TはAそのもの。−180°の周波数で、Tは約11よ。

四国めたん：−180°の周波数は約2.7GHz。T＝1の周波数は約7.8GHzで、ずっと高いわ。

ず

ずんだもん質問

利得を20倍にすると、何が変わるのだ？

め

四国めたん

βを0.05にすると、Tは全体に26dB下がり、−180°の周波数では約0.57よ。

め

四国めたん

T＝1の周波数は約2.0GHz。−180°の約2.7GHzより低いから、安定ね。

四国めたん：時間波形で見ると、利得1倍の回路は、入力を少し変えただけで、揺れがどんどん大きくなるわ。

め

四国めたん

利得20倍の回路は、揺れながらも、最後には落ち着くの。

ず

ずんだもん

ボクのオペアンプが発振したのは、位相が180°回ったところで、Tがまだ1以上だったからなのだ！

め

四国めたん

−180°までの余裕を、位相余裕と呼ぶわ。T＝1の周波数で、あと何度残っているかよ。

め

四国めたん

利得20倍の回路は約15°。余裕が小さいから、揺れが長く続いたの。

四国めたん：直すには、主極をもっと下げて、T＝1の周波数を下げるの。そのための容量を、補償容量と呼ぶわ。

ず

ずんだもん

主極を下げたら、利得が早く下がってしまうのだ。

め

四国めたん

そうよ。その代わり、位相が回りきる前に、T＝1になるの。安定のために、帯域を手放すのね。

め

四国めたん

説明のため、段の間からグラウンドへ10pFを足すと、T＝1は約310MHzに下がるわ。

め

四国めたん

位相余裕は約54°。利得1倍でも、安定よ。

四国めたん：波形も、行き過ぎが小さく、すぐに落ち着くわ。

め

四国めたん

本物は、第8回のように、Ccを2段目の入力と出力の間に入れるの。

四国めたん：2段目の利得が約35倍だから、ミラー効果でCcは約36倍に見えるの。約0.28pFで、さっきの10pFと同じ主極になるわ。

め

四国めたん

そのうえ、極の分離も起きるのよ。

ず

ずんだもん質問

Cgdと同じ場所なら、右半平面零点もできるのだ？

め

四国めたん

そうよ。零点はgm/(2π(Cc+Cgd))。Ccが大きいぶん約370MHzまで下がって、T＝1の周波数より低くなるから、このままでは位相余裕がほぼ残らないの。

四国めたん：今日は、発振の条件と、補償の考え方まで。零点の対策と容量の決め方は第14回よ。

12まとめ

め

四国めたん

まとめましょう。ノードごとの抵抗×容量の和から、主極が読めるわ。

四国めたん：極が1つ増えるごとに、傾きは−20dB/decずつ急になり、位相は最大90°ずつ遅れるの。零点は逆よ。

め

四国めたん

ただし右半平面零点は、利得が上がるのに、位相は遅れるわ。

四国めたん：極が増えると、位相が−180°まで回るわ。その周波数でTが1以上だと、発振するの。

ず

ずんだもん

主極は時定数の和で見積もれて、主極を下げる補償容量で、発振を止められるのだ！

ず

ずんだもん

回路図から極を読んで、発振の理由もレポートに書けるのだ！

め

四国めたん

ずんだもん
