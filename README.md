# ずんだもんと学ぶアナログ回路（ウェブ版）

ずんだもんと四国めたんの掛け合いで学ぶ、アナログ回路のウェブ教科書です。
公開ページ: https://keio-csg.github.io/zundamon-analog/

第1〜8回はページ上部の「日本語 / English」で切り替えられます。英語版は本文・図・操作パネルに対応し、読み進めている節を保って切り替えます。
英語版の目次: https://keio-csg.github.io/zundamon-analog/index_en.html
第9回と余談は現在、日本語版のみです。

このリポジトリには、台本と動画から生成した静的サイトだけを置いています（生成元の台本・制作パイプラインは別管理）。

## クレジット
- VOICEVOX:ずんだもん、VOICEVOX:四国めたん
- 立ち絵：坂本アヒル（配布立ち絵素材を切り抜いて使用）
