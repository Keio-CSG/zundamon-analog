第3回

gmとソース接地増幅回路

アナログ回路入門シリーズ第3回です。

MOSFETで信号を増幅するカギは、相互コンダクタンス gm と小信号モデル。特性カーブの接線から gm を定義し、NMOSを小信号等価回路（gm·vgs の電圧制御電流源と ro の並列）に置き換える手順を、回路図を一つずつ変形しながら解説します。いちばん基本の増幅回路「ソース接地増幅回路」では、負荷線と入出力特性（大信号解析）を見たあと、小信号回路図への変形から電圧利得 Av = −gm(RD∥ro) を導き、グラフの傾きと一致することを確かめます。

後半は、小信号回路を速く解くコツ（入力抵抗 Rin・出力抵抗 Rout・Av = −Gm·Rout）を、ダイオード接続とソース抵抗 RS の例題で練習し、バイパス容量・結合容量、周波数特性と SPICE の AC 解析の考え方まで扱います。

め

四国めたん

手順2。G・D・Sの3端子は、そのまま小信号モデルの3端子になるわ。

四国めたん：ゲートには電流が流れないから、GとSの間は開放ね。

四国めたん

vgsはゲートとソースの間の小信号電圧。ゲート側をプラスにとるの。

四国めたん：手順3。DからSの向きにgm·vgsを流す、電圧制御電流源を置くわ。

ず

ずんだもん

第1回で出てきた、従属電源そのものなのだ！

め

四国めたん

手順4。前回のチャネル長変調の分として、並列にroを入れるの。

四国めたん：前回求めたとおり、VGS=0.8 Vならroは約62 kΩね。

め

四国めたん

まとめると、id=gm·vgs+vds/roと書けるわ。

四国めたん：基板はソースにつないだままなので、基板バイアス効果の項は0になるわ。

13小信号回路を速く解くコツ：Rin・Rout・Gm 動画 9:44

め

四国めたん

ここからは、小信号回路を速く解くコツを、例題で練習しましょう。

め

四国めたん

まず入力抵抗Rin。入力から見た抵抗で、ソース接地ではゲートだから無限大よ。

四国めたん：出力抵抗Routは、入力を0にしたときに、出力から見た抵抗。RD∥roで約4.6 kΩね。

め

四国めたん

求め方は、テスト電源vxをつなぎ、流れ込む電流ixを計算。抵抗はvx/ixよ。

め

四国めたん

利得は、入力を電流に変える割合Gmと、Routの積。Av＝−Gm·Routと考えるの。

ず

ずんだもん

ソース接地ならGm=gmだから、Av＝−gm(RD∥ro)が、すぐ出るのだ！

め

四国めたん

練習に、ゲートとドレインをつないだMOSFET。ダイオード接続と呼ぶ形よ。

め

四国めたん

vgs=vxで、ix=gm·vx+vx/ro。抵抗は、1/gmとroの並列ね。

四国めたん：roのほうがずっと大きいから、抵抗はほぼ1/gm。第4回で、この形を使うわ。

め

四国めたん

次は、ソースとグラウンドの間に抵抗RSを入れた回路。仮にRS=1 kΩとするわ。

め

四国めたん

まず大信号。ゲートの直流を1.0 Vに上げると、VOUTは約0.88 Vで、飽和領域のままよ。

め

四国めたん

小信号では、ソースの電圧がid·RS。だからvgs=vin−id·RSになるの。

四国めたん：roを省くと、Gm=gm/(1+gm·RS)。もとのgmより小さくなるわ。

め

四国めたん

だからAv≈−RD/(RS+1/gm)で約−2.3。モデルの傾きも約−2.2よ。

ず

ずんだもん質問

利得が下がっちゃったのだ。何がうれしいのだ？

め

四国めたん

gmが1割変わっても、利得は約5%しか変わらない。だから、ゆがみにくくなるの。

め

四国めたん

1/gmは、MOSFETをソースから見た抵抗。くわしくは第5回で見ましょう。

ず

ずんだもん質問

RSに大きなコンデンサを並列につないだら、どうなるのだ？

め

四国めたん

小信号では短絡なので、RSが消えて利得は約−4。これをバイパス容量と呼ぶの。

ず

ずんだもん質問

信号源の直流が0 Vだったら、ゲートの0.8 Vはどうやってかけるのだ？

め

四国めたん

間に結合容量を入れて、ゲートには大きな抵抗RGを通して0.8 Vをかけるの。

四国めたん：直流では容量は開放。ゲートに電流は流れないから、ゲートは0.8 Vのままよ。

め

四国めたん

小信号では容量も0.8 Vも短絡。入力抵抗は無限大から、RGの100 kΩに変わるの。
