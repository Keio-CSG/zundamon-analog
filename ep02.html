ずんだもんと学ぶアナログ回路

第2回

チャネル長変調・出力抵抗と基板バイアス効果

アナログ回路入門シリーズ第2回です。実験レポートの特性グラフが、飽和領域なのに少し右上がり……その正体を探ります。

振り返りましょう。飽和領域のMOSFETは、VGSで電流が決まる電流源だったわね。

四国めたん：前回見た飽和領域のグラフも、VDSを上げると、少しだけ右上がりだったの。

め

四国めたん

測定ミスではないわ。今日はこの傾きの正体と出力抵抗ro、基板バイアス効果を見ましょう。

ず

ずんだもん

よろしくなのだ！レポートの考察を書けるようにするのだ！

め

四国めたん

なお、この動画の数値は、180 nm程度のCMOSを想定した説明用の値よ。

四国めたん

前回の二乗則はID＝½K·Vov²。係数Kは、μnCox·W/Lのことよ。

四国めたん：Wはチャネルの幅、Lは長さ。このモデルでは、K＝2 mA/V²にしてあるわ。

2傾きを測ってみる 動画 0:54

め

四国めたん

VGSを1.2 Vに固定して、VDSを1.0 Vから1.5 Vに上げてみるわ。

ず

ずんだもん

IDが0.704 mAから0.736 mAに増えたのだ。ちょっとだけなのだ。

増え方は5%足らず。でも増幅回路では、この差が効いてくるの。

ずんだもん

理想の電流源なら、VDSを変えても電流は変わらないはずなのだ。

め

3原因：ピンチオフ点が動く 動画 1:24

ず

ずんだもん質問

でも前回、飽和領域では平らになるって習ったのだ。どうして傾くのだ？

め

四国めたん

断面に戻りましょう。飽和領域では、ドレイン端でチャネルが途切れていたわね。

め

四国めたん

このピンチオフ点の電位は、ソースから見てVovに保たれるの。

四国めたん：VDSのうち、それを超えた分は、ピンチオフ点とドレインの間にかかるのよ。

四国めたん：VDSを上げると、このすき間が広がって、ピンチオフ点がソース側へ動くの。

ず

ずんだもん質問

チャネルが短くなるのだ？

め

四国めたん

ええ。実効的なチャネル長が、少しだけ短くなる。これがチャネル長変調よ。

ず

ずんだもん質問

チャネルが短くなると、どうして電流が増えるのだ？

め

四国めたん

チャネルにかかる電圧はVovのまま、長さだけが短くなるからよ。

四国めたん：IDはW/Lに比例するから、Lが縮めばIDは増えるの。

4式で表す：ID ≈ ½KVov²(1+λVDS) 動画 2:13

め

四国めたん

簡単のため、縮む割合はVDSに比例するとみなして、二乗則に(1+λVDS)をかけるの。

め

四国めたん

λはチャネル長変調係数。このモデルでは、λ＝0.1 /Vにしてあるわ。

5出力抵抗 ro と等価回路 動画 2:26

め

四国めたん

VGSを固定したときの、この傾きの逆数が出力抵抗roよ。ΔVDSをΔIDで割ったものね。

め

四国めたん

回路図では、飽和領域のMOSFETを、D–S間の電流源とroの並列に置き換えるの。

四国めたん：電流源はVGSで決まる½KVov²。そこにroを流れるVDS/roが足されてIDになるわ。

ず

ずんだもん

回路理論で習った、ノートンの等価回路みたいなのだ！

め

四国めたん

その通り。roが無限大なら理想電流源。roが大きいほど理想に近いのよ。

め

四国めたん

VDSで微分すると、傾きはλ・½KVov²。その逆数がroね。

四国めたん：λVDS≪1なら、IDは½KVov²とほぼ等しいから、ro≈1/(λID)と書けるの。

め

四国めたん

VGS=1.2 Vなら½KVov²＝0.64 mA。roは1/(0.1×0.64)で、約16 kΩよ。

ず

ずんだもん

さっきの測定でも、0.5 V÷0.032 mAで約16 kΩ。ぴったりなのだ！

ずんだもん：でも、IDにグラフの0.72 mAを入れると、少しずれるのだ？

め

四国めたん

約14 kΩね。1割ほどずれるけど、手計算の目安としてよく使う式なのよ。

ず

ずんだもん質問

roは、流す電流によって変わるのだ？

め

四国めたん

ええ、roはIDにほぼ反比例。VGS=0.8 Vで電流が約1/4なら、roは約4倍の62 kΩよ。

め

四国めたん

λを変えて重ねてみましょう。roが大きいほど傾き1/roが小さく、平らになるの。

ず

ずんだもん

roが小さいと、右上がりが急になるのだ。

6アーリー電圧 VA 動画 4:10

め

四国めたん

λは0.1にそろえて、VGSの違う直線を、VDSが負の側へ伸ばしてみましょう。

ず

ずんだもん

どの線も、VDS＝−10 Vの一点で交わったのだ！

め

四国めたん

このモデルでは、ちょうど一点になるの。この電圧の大きさがアーリー電圧VA=1/λよ。

め

四国めたん

VAを使うと、ro≈VA/IDとも書けるわ。VAが大きいほど、良い電流源ね。

7チャネル長 L とλ 動画 4:37

ず

ずんだもん質問

roを大きくするには、どうすればいいのだ？

め

四国めたん

一つの方法は、チャネル長Lを長くすることよ。

め

四国めたん

ピンチオフ点が同じだけ動いても、もとのLが長ければ、縮む割合は小さいでしょう？

四国めたん：だから、Lを長くするとλは小さくなる傾向があるの。

め

四国めたん

逆に、先端プロセスでLをとても短くすると、λが大きく、roは小さくなりがちなの。

8なぜ ro が大事か：固有利得 gm·ro 動画 5:02

ず

ずんだもん質問

そもそも、roが小さいと何が困るのだ？

め

四国めたん

1個の増幅回路で、負荷を理想電流源にすると、利得の大きさがgm·roになるからよ。

四国めたん：これを固有利得と呼ぶの。gmはVGSに対するIDの変化の割合で、次回くわしくやるわ。

め

四国めたん

λを無視するとgm＝K·Vov=1.6 mS。ro≈16 kΩとかけて、目安は約25倍ね。

め

四国めたん

λも入れてモデルで計算すると、gmは約1.8 mSで、約28倍になるわ。

ず

ずんだもん

roが小さいと、gm·roも小さくなって、増幅しにくくなるのだ。

め

四国めたん

ええ。だからLを短くした素子では固有利得が下がりがちで、回路の工夫が要るのよ。

9基板バイアス効果 動画 5:50

ず

ずんだもん

そういえば前回、基板端子はソースにつながっているとしたのだ。

め

四国めたん

ええ。でもICのNMOSでは、基板は、まとめてグラウンドにつなぐことが多いの。

め

四国めたん

トランジスタを縦に積むと、上のソースは、グラウンドより高い電位になるわね。

め

四国めたん

ソースの電位から基板の電位を引いた電圧がVSB。VSBが正だと、Vthが上がるの。

ず

ずんだもん質問

VGSは同じなのに、どうしてVthが変わるのだ？

め

四国めたん

VSBが正だと、チャネルの下の空乏層、つまり動ける電荷のない層が広がるの。

め

四国めたん

空乏層に残るイオンの電荷が増える分、チャネルを作るのに大きなゲート電圧が要るの。

四国めたん：これを基板バイアス効果、またはボディ効果と呼ぶわ。

め

四国めたん

式で書くとこう。VSBが大きいほどVthは上がるけど、増え方はゆるやかになるの。

四国めたん：γと2φFはプロセスで決まる定数よ。ここではγ＝0.4√V、2φF=0.7 Vとしましょう。

め

四国めたん

VSB=0.5 Vにすると、Vthは0.40 Vから約0.50 Vに上がるわ。

ず

ずんだもん質問

VGSが同じでも、電流は減っちゃうのだ？

め

四国めたん

ええ。VGSとVDSを1.2 Vに保っても、IDは0.72 mAから約0.54 mAに減るの。

四国めたん：ソースが接地されていない回路では、この効果を見込んで設計するのよ。
