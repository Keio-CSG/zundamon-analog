2外来の妨害と部品自身の雑音 動画 0:17

め

四国めたん

雑音はランダムな揺らぎ。信号の変化と区別しにくく、測定の限界になるの。

め

四国めたん

外から入る電源のハムや電磁的な妨害と、部品自身が作る雑音は分けて考えるわ。

ず

ずんだもん質問

外からの妨害を防いでも、部品の中から雑音が出るのだ？

め

四国めたん

ええ。抵抗の中の電荷が熱で動くので、電流を流していなくても熱雑音があるの。

め

四国めたん

差動対は同相の妨害を抑えるけれど、独立な内部雑音まで消してはくれないわ。

3平均とRMS 動画 0:46

ず

ずんだもん質問

正と負に揺れるなら、平均すれば0になって消えるのだ？

め

四国めたん

平均が0でも、揺らぎの大きさは残るの。有限時間の平均も、毎回同じではないわ。

四国めたん：大きさは実効値、RMSで表すわ。電圧を2乗して平均し、平方根を取るの。

ず

ずんだもん

2乗するから、正負で打ち消されないのだ！

4PSD・熱雑音・密度の平方根 動画 1:08

め

四国めたん

周波数ごとの雑音は、電圧の2乗の密度Svで見るの。単位はV²/Hzよ。

め

四国めたん

今回は正の周波数だけで表す、一側の密度を使うわ。

四国めたん：低い周波数の抵抗の熱雑音は、密度がほぼ一定。これを白色雑音と呼ぶの。

四国めたん：抵抗の開放端の電圧雑音はSv＝4kTR。Tは絶対温度、kは定数よ。

ず

ずんだもん質問

抵抗が大きいほど、電圧の雑音も大きくなるのだ？

め

四国めたん

この開放端の電圧雑音では、そうよ。回路につないだ後は伝わり方も計算するの。

四国めたん：仕様表では、その平方根enをよく使うわ。単位はV/√Hzね。

ず

ずんだもん

nV/√Hzと書いてあっても、そのまま波形の電圧ではないのだ！

5帯域内の雑音を計算する 動画 1:56

め

四国めたん

見ている周波数範囲で、Svを積分するの。その面積が雑音の分散になるわ。

め

四国めたん

面積の平方根を取ると、雑音の実効値。密度と電圧の大きさを区別してね。

め

四国めたん

白色雑音と幅Bの矩形帯域なら、実効値はen√B＝√(4kTRB)よ。

め

四国めたん

温度300K、抵抗10 kΩ、帯域20kHzで計算しましょう。

め

四国めたん

密度の平方根は約12.9nV/√Hz。これはまだ実効電圧ではないの。

ず

ずんだもん

20kHzの範囲を足すと、雑音は約1.82µV RMSになるのだ！

め

四国めたん

抵抗を4倍にすると、実効値は2倍。約3.64µVになるわ。

め

四国めたん

抵抗はそのままで帯域を4倍にしても、雑音は2倍になるの。

ず

ずんだもん

必要以上に広い帯域は、余分な雑音まで通すのだ！

6等価雑音帯域 動画 2:52

め

四国めたん

実際のフィルタは、矩形ではないわ。伝達の大きさの2乗を掛けて積分するの。

め

四国めたん

同じ雑音の面積になる矩形の幅を、等価雑音帯域と呼ぶわ。

四国めたん：1段のRC低域フィルタでは、等価雑音帯域は−3dB帯域の約1.57倍ね。

ず

ずんだもん

前回の−3dB帯域を、そのままBに入れないようにするのだ。

7独立な雑音と二乗和 動画 3:16

め

四国めたん

独立な雑音源を足すときは、実効電圧ではなく、分散を足すの。

め

四国めたん

同じ場所と帯域へ換算して、実効値を2乗し、足してから平方根を取るわ。

ず

ずんだもん

1.82µVが2つなら、合計は約2.57µV。3.64µVではないのだ！

め

四国めたん

相関があると交差項も必要よ。同じ揺らぎを2回数えないでね。

8MOSFETの熱雑音と1/f雑音 動画 3:40

め

四国めたん

MOSFETも熱雑音を作るわ。チャネルの電流雑音を、小信号モデルに加えるの。

め

四国めたん

長チャネルの強反転近似では、入力換算の熱雑音PSDは4kTγ/gmよ。

め

四国めたん

この近似ではgmを大きくすると、入力換算の熱雑音が減るの。

め

四国めたん

γや他の雑音源は素子や動作点で変わるわ。実デバイスはモデルや測定で確認ね。

四国めたん：低い周波数では、1/f雑音も目立つの。PSDが、およそ周波数に反比例するわ。

ず

ずんだもん

平方根の密度なら、1/√fで下がるのだ。グラフの単位も見るのだ！

め

四国めたん

白色雑音と1/f雑音が等しくなる周波数が、雑音のコーナー周波数ね。

め

四国めたん

1/f雑音の計算には、下限の周波数も必要。観測時間やフィルタの条件を見るの。

9入力換算雑音とSNR 動画 4:31

め

四国めたん

増幅器の出力雑音を、利得の大きさで割ると入力換算雑音。比較しやすくなるわ。

め

四国めたん

今日は帯域内の利得が一定の場合。周波数で変わるなら、密度ごとに換算するの。

ず

ずんだもん質問

入力の雑音も100倍にしたら、出力の雑音も100倍なのだ？

め

四国めたん

そうよ。1.82µVが約182µVに。信号も雑音も一緒に大きくなるの。

め

四国めたん

SNRは信号と雑音の比。電圧の実効値なら、20log10でdBにするわ。

め

四国めたん

信号10µV RMS、雑音1.82µV RMSなら、SNRは約14.8dBね。

ず

ずんだもん

両方100倍なら、比は同じ。増幅するだけではSNRは良くならないのだ！

め

四国めたん

実際の増幅器は自分の雑音も加えるわ。入力換算して、独立なら分散を足すの。

め

四国めたん

信号源、抵抗、増幅器。それぞれの雑音が、どこからどう伝わるか整理しましょう。

ず

ずんだもん

必要な帯域に絞り、抵抗と素子を選ぶ。信号を失わない条件も確認するのだ！
